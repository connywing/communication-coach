# 训练路径

> 四周是默认节奏，不是固定课程。路径跟着表现走，不跟着日历走。

## 一、总体安排

默认 4 个阶段，每个阶段 3–7 次训练（每次 10–15 分钟）。可以跳阶段、回退、穿插，不必按顺序打卡。

```text
内容生成 → 逻辑组织 → 语言表达 → 场景应用
   ↑            ↑            ↑           │
   └──────── 根据表现回退/穿插 ───────────┘
```

阶段不是“课程章节”，而是**当前主要训练重心**。用户可能同时在两个阶段之间，允许。

## 二、阶段一 · 内容生成

**目标：** 面对开放问题，能自己找到事实、细节和观点，不再“脑子空白”。

**训练重点：**
- 观察具体行为/细节
- 区分事实与评价
- 从一个事实提炼判断
- 用“因为/这带来……”连接事实与判断
- 建立最小素材意识

**典型题目：**
- 夸一个最近接触的人
- 讲一件最近印象深刻的小事
- 说一个你观察到的现象
- 评价一个同事/朋友的一个特点

**单次结构：** 定题 → 第一次表达 → 引导找事实 → 形成判断 → 三句话重说 → 对比。

**退出标准（无提示下）：**
- 能给出一个可验证的事实/细节；
- 能给出一个与事实匹配的判断；
- 能用一句话说明“为什么这个事实支持这个判断”；
- 同类任务连续 2 次做到。

**未达标信号：** 仍然只有形容词；追问三次仍无具体内容；需要教练提供事实才能说。

**下一步：** 进入阶段二，或把内容生成放到一个简单场景里（如“会上夸同事”）。

## 三、阶段二 · 逻辑组织

**目标：** 有内容时，能快速找到重点、排出顺序、让听者跟得上。

**训练重点：**
- 一句话结论
- 结论先行
- 理由/例子分组与排序
- 观点与支撑的连接
- 根据听众选择顺序
- 该短则短，不机械套结构

**典型题目：**
- 用 30 秒说清一个观点
- 把一段混乱的项目更新重说
- 给一个建议，说清理由和例子
- 讲一个项目经过（背景-问题-行动-结果）

**单次结构：** 取材料 → 找核心句 → 选结构 → 排点 → 三句话 → 展开 → 对比。

**退出标准（无提示下）：**
- 开口第一句给出结论/核心判断；
- 理由按一个清楚原则排序；
- 每个例子能说明它支持哪句；
- 能把同一内容压到 30 秒，也能展开到 2 分钟；
- 连续 2 次做到。

**未达标信号：** 结论仍在最后；点与点之间靠“然后”连接；结构完整但内容空。

**下一步：** 进入阶段三，或开始简单场景模拟。

## 四、阶段三 · 语言表达与自然度

**目标：** 说得具体、清楚、简洁，并开始像“自己说的话”，而不是背模板。

**训练重点：**
- 空泛词具体化
- 删重复、无效铺垫
- 长句拆短、一句一意
- 口语化但不随意
- 同一内容对不同对象说
- 脱稿复述

**典型题目：**
- 把一句空泛评价改具体
- 把一段话压到一半
- 用朋友/领导两种说法讲同一件事
- 脱稿讲一个最近的项目/经历

**单次结构：** 取原话 → 标一个问题 → 找核心句 → 只改一处 → 读一遍 → 重说 → 对比。

**退出标准（无提示下）：**
- 能用一个具体事实替换空泛评价；
- 能压缩 50% 不丢核心；
- 长句能拆成可一口气说完的短句；
- 能对两个对象调整说法；
- 连续 2 次做到。

**未达标信号：** 改完更绕；为了自然加口头禅；只会一种语体。

**下一步：** 进入阶段四，或选一个真实场景做综合训练。

## 五、阶段四 · 场景应用

**目标：** 把内容、结构、语言放到真实压力下用出来，能接住追问和互动。

**训练重点：**
- 临场快速形成观点
- 回应对方真正关心的问题
- 多轮追问
- 表达不同意见/拒绝/反馈
- 情绪与关系处理
- 复盘与迁移

**典型题目：**
- 周会汇报 + 领导追问
- 会上被临时点名
- 给同事负面反馈
- 拒绝临时需求
- 面试追问
- 朋友倾诉/分歧

**单次结构：** 收背景 → 角色卡 → 2–4 轮 → 自评 → 一个主问题 → 重来一轮 → 迁移。

**退出标准（无提示下）：**
- 第一轮回应核心问题；
- 被追问不逃，能回到主线；
- 给出明确结论/下一步；
- 能根据对方反应调整；
- 连续 2 次做到。

**未达标信号：** 一追问就重复原话；只顾自己说完；忽略对方情绪/顾虑。

**下一步：** 进入维持期：每周 1–2 次真实场景复盘，或挑战多方/高压力场景。

## 六、如何定位起点

有初始诊断：按主问题定位，不必从阶段一硬走。

| 诊断主问题 | 起点 |
|---|---|
| CG 系列 | 阶段一 |
| LO 系列 | 阶段二（先用用户已有内容，不补内容） |
| LE 系列 | 阶段三 |
| SA 系列 | 阶段四（但先补必要的内容/结构） |
| 混合，且内容空 | 阶段一优先，不要在空内容上练结构 |
| 混合，且结构乱 | 阶段二优先，不要先抠措辞 |

没有诊断：用一道开放题 + 一道场景题快速判断，不必走完整三题。

## 七、升级 / 降级 / 跳阶段

**升级条件（同时满足）：**
1. 同类任务连续 2 次在无提示下达到该阶段退出标准；
2. 用户自己能在复盘里说出方法；
3. 用户没有明显挫败/抗拒。

**不升级：**
- 一次表现好；
- 用户只是理解了概念，还没用出来；
- 用户靠提示完成；
- 用户状态不好/疲惫。

**降级条件（任一）：**
- 连续 2 次明显卡住/挫败；
- 任务难度明显超出当前能力；
- 用户明确说“太难了/想简单点”；
- 基础动作又退回（如结论又消失）。

**跳阶段：**
- 用户已有明显基础（第一次表达就结构清楚、有事实），可直接从阶段三/四开始；
- 用户有紧迫真实场景，可先用阶段四，但训练中补内容/结构短板；
- 跳过后要在 1–2 次内确认基础动作没漏。

## 八、每周节奏

不要求每日打卡。推荐：

- **常规周：** 3 次短训练（10–15 分钟）+ 1 次真实场景复盘。
- **忙碌周：** 1–2 次，保持手感即可。
- **冲刺周（有重要发言/面试）：** 2–3 次场景模拟，中间穿插一次内容/结构补强。
- **休息周：** 0 次也可以，不制造负罪感。

**一次训练只练一个点。** 不要为了“覆盖阶段”在一次里塞四个模块。

## 九、训练模式菜单

| 模式 | 时长 | 适合 |
|---|---|---|
| 每日短练 | 8–10 分钟 | 保持手感，一个小题 + 一次重说 |
| 自由表达 | 10–15 分钟 | 没有明确目标，按诊断切换模块 |
| 专项训练 | 10–15 分钟 | 锁定一个能力（内容/结构/语言/场景） |
| 场景模拟 | 15 分钟 | 真实沟通，多轮互动 |
| 阶段评估 | 20 分钟 | 2–3 个任务，看是否升级/调整重点 |
| 真实复盘 | 10 分钟 | 用户讲一次真实表达，复盘一个点 |

## 十、四周示例（可调整）

| 周 | 重点 | 训练组合 | 周末复盘 |
|---|---|---|---|
| 第 1 周 | 内容生成 | 2 次观察/夸人 + 1 次经历 | 这周最能说具体的一次是什么？ |
| 第 2 周 | 逻辑组织 | 2 次观点/汇报 + 1 次结构改写 | 哪次结论最清楚？哪次又晚了？ |
| 第 3 周 | 语言表达 | 2 次精简/具体化 + 1 次口语化 | 哪句话改完最明显？ |
| 第 4 周 | 场景应用 | 2 次真实场景模拟 + 1 次综合 | 真实场景里用出了哪个动作？ |

**这不是打卡表。** 如果第 1 周就发现结构是主问题，第 2 周可以提前；如果第 3 周语言已经稳定，可以直接进第 4 周。

## 十一、阶段评估怎么做

每 3–4 周，或准备换阶段前，做一次 20 分钟的评估。不是考试，不给分数。

**三个题：**
1. 一个熟悉题：看核心动作是否稳定。
2. 一个新题：看方法能不能迁移。
3. 一个场景题：看压力下还能不能用出来。

**规则：**
- 不给提示，不中途教学。
- 用户卡住时只记录，不救场；结束后再复盘。
- 不要求三道都完美，只看目标动作。

**输出三句话：**

```markdown
- 保留：……（已经稳定的动作）
- 升级/回退：……（一个方向 + 依据）
- 下周：……（一个具体任务）
```

如果三个题表现差异很大，说明能力还不稳定，先不升级；换一个相似题再确认一次。

## 十二、平台期处理

用户连续 3–4 次没有明显变化时：

1. **换题型，不换能力。** 还是练“具体化”，但换成用户更熟悉的场景。
2. **缩小任务。** 从“说 3 分钟”改成“只说第一句”。
3. **换反馈角度。** 之前说“缺事实”，这次说“听者会问什么”。
4. **让用户自评。** “你觉得这次和上次比，哪里不一样？”
5. **暂停专项，做一次自由表达。** 可能只是疲劳。
6. **不要加更多理论。** 平台期通常不是“不懂”，是“没练熟”或“任务不对”。

## 十三、阶段复盘（每 1–2 周）

用 5 个问题，不超过 10 分钟：

1. 这段时间主要练了什么？
2. 哪个问题出现得最多？
3. 哪个具体瞬间让你觉得“这次不一样”？
4. 哪个问题还没改善？
5. 下周只练一个什么？

输出三句话：**进步证据 / 仍卡的点 / 下周重点**。不做长篇报告。

## 十四、迁移检查

每个阶段结束前问：

> “如果明天遇到一个类似但不完全一样的场景，你会怎么做？”

用户能说出“第一步做什么”，才算迁移；只会复述结构名称不算。

迁移失败时，不要退回讲理论；换一个更接近真实场景的题再练一次。
