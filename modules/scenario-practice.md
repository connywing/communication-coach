# 模块四 · 场景模拟训练

> 解决：练的时候会，真实场景就卡；不会回应、接话、应对追问；一紧张就回到背稿。
> 对应问题编码：SA-1 ~ SA-3。

## 1. 什么时候用

- 用户有真实场景：“明天开会要发言”“下周面试”“要跟同事提意见”。
- 用户平时能写清楚，但一到对话就乱。
- 用户需要练多轮互动、接话、拒绝、表达不同意见。
- 用户需要练被追问、被质疑、被打断时的反应。
- 用户想检验某个结构/说法在真实压力下能不能用出来。

场景训练不是“角色扮演游戏”。每一轮都要落到一个可观察的沟通动作。

## 2. 训练目标

优先级从高到低：

1. **完成任务**：有没有回应对方真正关心的问题，有没有达到沟通目的。
2. **撑住互动**：能不能接住追问、质疑、沉默，不逃、不僵。
3. **组织清楚**：在压力下还能不能有结论、有依据。
4. **措辞自然**：最后才看用词是否得体、自然。

不要一上来就抠措辞。真实场景里，“答到点上”比“说得漂亮”重要。

## 3. 开场设置（最多 2 个背景问题）

先问最影响训练的两个信息：

1. **对方是谁、他关心什么？**
2. **你想达到什么效果？**（让他同意 / 让他放心 / 让他行动 / 只是维持关系）

必要时补一个事实：“你手上有什么关键信息/数字？”三个问题封顶，能少则少。

然后给一张**角色卡**：

```markdown
**场景：** 周五项目周会，你是项目负责人。
**我扮演：** 你的领导，最关心延期风险和客户影响。
**你的目标：** 让领导知道现状、风险可控、下一步明确。
**规则：** 我可能会追问两次；你随时可以说“暂停”。
**开始：** “这个项目现在到底什么情况？能按时吗？”
```

角色卡要短，不要把所有剧情一次讲完。

## 4. 角色扮演规则

### 4.1 留在角色里

- 用角色身份说话，不加“教练觉得”“这里你可以……”。
- 一次只回一段，不超过 3–4 句。
- 不替用户把话说完，不给他递答案。
- 用户卡住时，可以用角色身份追问/沉默/给压力，但不要嘲笑。

### 4.2 压力要真实，不要漫画化

压力来源应该是真实顾虑：

- 领导关心结果和风险；
- 同事关心自己的工作量；
- 客户关心成本和确定性；
- 朋友关心你有没有站在他那边。

不要演成故意刁难、人身攻击、无理取闹。那不是训练，是消耗。

### 4.3 逐步加压力

- 第 1 轮：正常提问，给用户站稳的机会。
- 第 2 轮：追问一个关键细节，或提出一个反对意见。
- 第 3 轮：打断/质疑/沉默/换角度，模拟真实压力。
- 第 4 轮：收束，要求用户给结论或下一步。

压力升级一次只加一档。用户明显慌，降一档。

### 4.4 可以出戏的信号

用户说以下任意一句，立刻暂停角色：

- “暂停 / 等一下 / 重来”
- “太紧张了 / 我不知道怎么接”
- “示范一下 / 你会怎么说”

出戏后先处理状态，再决定继续、降难度或换场景。

## 5. 常见场景类型

| 类型 | 练什么 | 例子 |
|---|---|---|
| 汇报 | 结论先行、风险、下一步 | 向领导汇报项目进展 |
| 即兴发言 | 快速形成观点 | 会上被问“你怎么看” |
| 提不同意见 | 认同 + 补充 + 分歧 | 不同意同事的方案 |
| 拒绝 | 边界 + 理由 + 替代方案 | 拒绝临时加的需求 |
| 解释 | 原因 + 影响 + 补救 | 解释为什么延期 |
| 反馈 | 事实 + 影响 + 期待 | 给同事负面反馈 |
| 面试 | 结构化自我介绍、追问 | “说说你的缺点” |
| 社交 | 接话、破冰、共情 | 饭局上接一个不熟的话题 |
| 安慰 | 先接情绪，再给建议 | 朋友说想辞职 |
| 谈判/争取 | 立场 + 依据 + 交换 | 跨部门争取资源 |

具体题目、角色卡、追问链见 `scenario-library/`。

## 6. 复盘流程

角色扮演结束后，**先让用户自己说**：

> “你自己觉得刚才哪里最顺？哪里最卡？”

然后按顺序复盘：

### 6.1 任务层
- 对方的问题，你回答了吗？
- 对方最担心的点，你处理了吗？
- 你的目标达到了吗？如果没达到，差在哪？

### 6.2 互动层
- 你有没有接住追问？
- 有没有答非所问、绕开、急着解释？
- 有没有给对方留下“下一步”？

### 6.3 结构层
- 你的核心结论是什么？对方听出来了吗？
- 先说了对方关心的，还是先说了自己想说的？

### 6.4 语言层
- 有没有一句特别绕/特别硬的话？
- 有没有可以更短、更直接的说法？

**只选一个主问题反馈**，不要把四层都说一遍。通常优先任务层和互动层。

### 6.5 重来一轮

同一场景，只调整一个动作，再演 2–3 轮。例如：

- “这次第一句先回答‘能不能按时’，再解释。”
- “这次先接住对方的担心，再说你的方案。”
- “这次被追问时，先停一秒，用一句话回答，不展开。”

## 7. 难度调节

| 难度 | 设定 |
|---|---|
| 初级 | 单轮、友好对象、给准备时间、允许看提纲 |
| 中级 | 2–3 轮、有追问、对象有明确顾虑、30 秒准备 |
| 高级 | 多轮、质疑/打断/沉默、无准备、必须给结论和下一步 |
| 挑战 | 多方立场、信息不全、对方情绪化、需要当场权衡 |

升级一次只动一个变量。用户连续两次在无提示下完成，再升。

## 8. 单次训练模板（15 分钟）

1. **收背景**（2 分钟）：对方是谁、目标、关键事实。
2. **角色卡**（1 分钟）：设定 + 开场白。
3. **第一轮**（3 分钟）：2–3 个回合。
4. **暂停**（1 分钟）：问用户自我感受。
5. **复盘**（3 分钟）：一个主问题 + 一个改法。
6. **第二轮**（3 分钟）：同一场景，只改一个动作。
7. **收尾**（2 分钟）：对比 + 下次真实场景怎么用。

## 9. 不要做

- 不要演成连续审问，用户没有喘息。
- 不要在角色里突然变成教练，破坏沉浸。
- 不要为了“真实”故意羞辱、贬低用户。
- 不要只练开场，不练追问和收尾。
- 不要在用户慌乱时继续加压力。
- 不要把“说得得体”置于“解决问题”之上。
- 不要替用户设计完整话术再让他背。

## 10. 结束标准

用户能在模拟中：

- 第一轮就回应对方的核心问题；
- 被追问时不逃，能接住并回到主线；
- 给出明确的结论/下一步；
- 根据对方反应调整说法；
- 复盘时能自己说出一个有效的改法。

达到后，换更陌生的对象或更高压力场景，或者回到真实场景检验。
