# 模块一 · 内容生成训练

> 解决：不知道说什么、没有观点、想不到例子、说不具体。
> 对应问题编码：CG-1 ~ CG-4。

## 1. 什么时候用

用户出现以下任一信号：

- “不知道说什么 / 没想法 / 脑子一片空白。”
- 回答只有一句抽象判断：“他人挺好的”“这个很重要”“我觉得还行”。
- 让他举例时，说“想不到 / 没有例子”。
- 说了一个观点，但问“为什么”就卡住。
- 描述事情只有结论，没有过程、行为、细节。

如果用户其实有内容，只是顺序乱或啰嗦，不要用本模块，转 `logical-organization.md` 或 `language-expression.md`。

## 2. 训练目标

不是让用户“多背素材”，而是建立一条可重复的内容生成链：

```text
缩小范围 → 找到具体事实 → 说出细节 → 形成判断 → 用事实支撑判断
```

训练结束时，用户应能自己完成一次：

> 一个具体事实 + 一个判断 + 一句“为什么这个事实能说明这个判断”。

## 3. 先判断卡在哪一层

| 表现 | 卡点 | 先用什么 |
|---|---|---|
| 完全没方向，不知道说谁/说什么 | 范围太大 | 缩小到“今天/这周、一个人、一件事” |
| 能说出人/事，但只有评价 | 缺少事实 | 摄像机测试 + 行为追问 |
| 有事实，但说不清说明什么 | 缺少判断 | 候选品质 + 证据连接 |
| 有判断，但问“为什么”就没了 | 缺少理由 | “这个行为带来了什么结果？” |
| 有理由，但很空 | 缺少细节/例子 | 5W1H + 一个场景还原 |

一次只处理一层。不要同时要求“说具体 + 有观点 + 有逻辑”。

## 4. 五步引导流程

### Step 1 · 缩小范围

不要问“你有什么想说的”，问一个边界清楚的问题：

- “就说今天，有没有一个人，做了一个让你稍微注意到的小动作？”
- “最近一周，有没有一件事让你当时‘咦’了一下？”
- “不用想大事，就说刚才路上/午饭时看到的一个画面。”

如果用户还说没有，继续缩小：

- “那说一个你熟悉的人，最近一次让你觉得‘他还挺靠谱’的瞬间。”
- “想不起来别人，就说你自己最近做成的一件小事。”

### Step 2 · 找到具体事实

用“摄像机测试”：

> 如果当时有一台摄像机，它能不能拍到/录到这个画面？

把评价翻译成行为：

| 用户说 | 追问 |
|---|---|
| “他很负责。” | “哪一次、他做了什么，让你觉得负责？” |
| “这个项目很成功。” | “哪个结果让你判断它成功？数字、反馈，还是按时交付？” |
| “她人很好。” | 择一问：“她具体做了什么？”/“她说了什么？”/“你当时怎么感觉到的？” |
| “气氛很尴尬。” | “谁说了什么，或者谁没说话？当时房间里发生了什么？” |

追问时一次只问一个，不要连发：

> “是主动举手、提前准备，还是帮别人补位？”

### Step 3 · 说出细节

拿到一个事实后，从下面挑 1–2 个维度追问，一次一个，不要贪多：

- **行为**：他具体做了什么？
- **语言**：他说了什么？怎么说的？
- **时间/场景**：什么时候？在哪？之前发生了什么？
- **结果**：这件事带来了什么变化？
- **对比**：跟平时/跟别人比，哪里不一样？

示例：

> 用户：“他开会前会整理问题。”
> 教练：“他整理的是什么问题？”
> 用户：“主要是上周遗留的几件事。”
> 教练：“整理完会发给谁？”
> 用户：“发在项目群里。”
> 教练：“有没有哪一次，因为这份整理，会议变短了？”

### Step 4 · 形成判断

不要替用户下结论，给候选方向让他选：

> “这个行为可能说明他有责任心、有闭环意识，或者比较体贴。你觉得哪个最贴近你看到的？”

选完后，要求证据连接：

> “如果用一句话说‘他很有闭环意识’，你刚才说的哪个细节能支撑这句话？”

如果用户选的判断和事实不匹配，不要否定，问：

> “这个细节能说明 A，也能说明 B。你更想表达哪一个？为什么？”

### Step 5 · 组成表达

给一个最小骨架，不写成完整范文：

```text
我注意到（事实）……
这让我觉得（判断）……
因为（这个事实带来的结果/影响）……
```

先让用户说 3 句。三句成立后，再决定是否扩展成 5 句。

## 5. 分题型提问库

### 人物评价类

顺序：**行为 → 细节 → 特点 → 价值**

- “你最先注意到他哪个动作？”
- “当时具体是什么情况？”
- “这个动作和旁边的人有什么不一样？”
- “如果只用一个词形容，你会选哪个？”
- “这个特点给团队/你带来了什么影响？”

不要一上来问“他有什么优点”。优点太抽象，用户容易卡。

### 经历/故事类

顺序：**事件 → 过程 → 感受 → 启发**

- “当时你在哪、在做什么？”
- “最先发生的是什么？然后呢？”
- “哪个瞬间你印象最深？”
- “当时你心里第一反应是什么？”
- “现在回头看，这件事让你明白了什么？”

如果用户说“就是一件小事”，回：“小事也行，就说那个让你停了一下的瞬间。”

### 观点类

顺序：**问题 → 判断 → 理由 → 例子 → 反例**

- “你自己的答案是什么？一句话。”
- “最主要是因为什么？”
- “有没有一个你亲眼见过的例子？”
- “有没有人可能不同意？他会怎么说？”
- “听完他的反对，你的观点要修正吗？”

注意：不要替用户选立场。用户说“都行”，就逼一个：“如果只能选一个，你选哪个？”

### 问题分析类

顺序：**现象 → 原因 → 影响 → 方案**

- “你观察到的具体现象是什么？”
- “可能的原因有哪些？先列 3 个。”
- “哪个原因最值得先查？”
- “这个问题不解决，会带来什么影响？”
- “如果只做一个动作，你先做什么？”

## 6. 关键技巧

### 6.1 一词三例

用户给出一个抽象词（负责、优秀、重要、尴尬），要求他说出三个具体例子，再选一个最好的。不要三个都写进表达。

### 6.2 事实与评价分离

拿用户的原话，标出哪部分是事实、哪部分是评价：

> “他工作很认真，经常加班到很晚。”
> 事实：加班到很晚。评价：工作很认真。
> 追问：加班到很晚，具体在做什么？是效率低，还是在补一个紧急问题？

这个练习能快速让用户看到“空泛”从哪里来。

### 6.3 候选品质法

用户说不出特点时，给 3 个候选，要求选一个并说理由：

> “主动、靠谱、会照顾人——哪个最像？为什么不是另外两个？”

选“不是另外两个”的理由，往往就是最好的证据。

### 6.4 反例检验

用户形成一个判断后，问一句：

> “有没有哪次他其实不是这样？”

能说出反例，判断会更真实；说不出，也能帮用户确认这个特点的稳定性。

### 6.5 细节只留一个

内容生成阶段容易越说越多。提醒：

> “先不用全说，只留最有力的那一个细节。”

## 7. 单次训练模板（10–15 分钟）

1. **定题**（1 分钟）：一个人 / 一件事 / 一个观点，范围具体。
2. **第一次表达**（2 分钟）：用户先说，不打断。
3. **诊断**（1 分钟）：只判断卡在哪一层。
4. **引导**（3–5 分钟）：按 L1–L4 逐级提问，拿到 1 个事实 + 1 个判断。
5. **重说**（2 分钟）：用“事实 → 判断 → 因为”三句。
6. **对比**（1 分钟）：第一次 vs 这一次，具体多了什么。
7. **迁移**（1 分钟）：问“下次遇到‘夸人/说经历’，你第一步会做什么？”

## 8. 常用练习

| 练习 | 做法 | 练什么 |
|---|---|---|
| 摄像机测试 | 把一句评价改写成可拍到的事实 | 事实感 |
| 一词三例 | 一个抽象词配三个具体例子 | 素材提取 |
| 细节五问 | 对一件事问 5 个维度：行为/语言/场景/结果/对比 | 细节 |
| 事实 vs 评价 | 标出一段话里的事实与评价 | 区分能力 |
| 候选品质 | 给 3 个词，选一个并排除其他 | 判断 |
| 三句话表达 | 事实 + 判断 + 因为 | 最小完整表达 |
| 换人说 | 同一件事，分别说给朋友/领导/陌生人听 | 场景适配 |

## 9. 不要做

- 不要用户一说“不知道”，就立刻给完整例子。
- 不要用“你可以说……”“比如说……”直接替用户编内容。
- 不要一次追问五个细节。
- 不要把“具体”变成“越长越好”。
- 不要因为用户选了不同的品质词就纠正他；先看证据是否支持。
- 不要在一轮里同时练“找事实”和“搭结构”。

## 10. 结束标准

用户能在**无提示**的情况下完成：

- 说出一个可验证的事实/细节；
- 给出一个与事实匹配的判断；
- 用“因为/这带来……”把两者连起来；
- 三句话能独立成立，不依赖教练补词。

达到后，下一次可以把题目换成用户不熟悉的人或事，或者进入逻辑组织训练。

## 11. 迁移提问

结束前问一句：

> “下次别人让你‘夸夸他/说说你的看法’，你第一步会做什么？”

期望答案不是背模板，而是：

> “先想一个具体画面/行为，再决定用什么词概括。”

如果用户答不上来，用一句话总结，不展开讲课。
