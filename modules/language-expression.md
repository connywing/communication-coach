# 模块三 · 语言表达训练

> 解决：说得空泛、重复、啰嗦、句子太长、书面腔、像背稿、不自然。
> 对应问题编码：LE-1 ~ LE-4。

## 1. 什么时候用

- 观点有了，但全是“很好、优秀、重要、有意义”这类大词。
- 一句话里反复说同一个意思。
- 铺垫很长，重点很晚才出现。
- 句子很长，听的人要自己断句。
- 用词像公文/作文，不像日常说话。
- 表达本身没大问题，但一听就是背的模板。
- 面对不同的人，语气完全不变。

如果问题是“没内容”，先做内容生成；如果“顺序乱”，先做逻辑组织。语言训练不负责补内容。

## 2. 训练目标

两条线，不要混在一起练：

**A. 清晰与精炼**
- 一句话只承担一个意思；
- 删掉不影响理解的重复、铺垫、模糊限定；
- 具体词替换空泛词；
- 句子短到能一口气说完。

**B. 自然与适配**
- 像说话，不像念稿；
- 能根据对象调整正式度、语气、详略；
- 同一内容能用不同说法表达；
- 不依赖固定模板。

## 3. 先判断是哪一种问题

| 表现 | 问题 | 先做什么 |
|---|---|---|
| “他很好、很优秀、很厉害” | 空泛 | 具体化：换成行为/事实 |
| 同一个意思说三遍 | 重复 | 找核心句，删重复 |
| 开头铺垫三句才进正题 | 无效铺垫 | 结论/重点前置 |
| 每句都很长，从句套从句 | 句子冗长 | 一句一意，切开 |
| “可能、也许、相对来说、一定程度上”很多 | 模糊/ hedging | 能确定就确定，不能确定说清条件 |
| 用词正式、结构工整，但不像说话 | 书面腔 | 口语化改写 |
| 说得流畅但像模板 | 背稿感 | 换对象/换说法/脱稿 |
| 对谁都用同一套话 | 不适配 | 场景角色切换 |

一次只处理一种。最常见顺序：**先具体，再精简，再自然。**

## 4. 五步改进流程

### Step 1 · 找到核心句

问用户：

> “这段话里，如果只能留一句，你留哪句？”

如果用户选不出，帮他找：

- 哪句是回答问题的？
- 哪句删了，意思就缺一块？
- 哪句只是解释/铺垫/重复？

把核心句写出来，作为改写的锚点。

### Step 2 · 删

按顺序删三类东西：

1. **重复**：同一个意思的第二种说法。
2. **无效铺垫**：“其实我想说的是”“怎么说呢”“这个事情是这样的”。
3. **不影响理解的限定**：“我个人觉得可能也许”“在一定程度上”。

删完读一遍，问：“意思少了吗？”没少就继续删。

**注意：** 不是所有“我觉得”都要删。表达个人观点时，“我觉得”是必要的；只有在一句话里反复出现时才处理。

### Step 3 · 具体化

空泛词 → 可感知的信息：

| 空泛 | 追问方向 | 可能的具体化 |
|---|---|---|
| 很好 | 好在哪个行为？ | “他会提前把问题列出来” |
| 很重要 | 对谁、影响什么？ | “少了这一步，后面三天都白做” |
| 很忙 | 忙在什么事上？ | “一天开了四个会，还要改方案” |
| 有意义 | 改变了什么？ | “我第一次觉得这事跟我有关” |
| 不方便 | 具体卡在哪？ | “周三之前我拿不到数据” |

不要用更华丽的形容词替换空泛词；要换成事实、动作、结果。

### Step 4 · 口语化

不是把书面语改成网络用语，而是让它像“你会对一个人说的话”。

三个检查：

1. **能不能一口气读完？** 不能就断句。
2. **会不会对朋友这么说？** 不会就换词。
3. **有没有不必要的名词化？** “进行了一个讨论” → “聊了一下”；“做出了一个决定” → “决定了”。

口语化允许：
- 短句、省略、重复一个关键词；
- “就是说”“你看”“其实”这类自然连接；
- 不完整的句子。

口语化不允许：
- 为了自然加一堆口头禅；
- 把正式场合该有的分寸也去掉。

### Step 5 · 适配对象

同一内容，至少练两个版本：

- 对朋友：短、直接、可以有情绪。
- 对领导：先结论、给依据、说影响。
- 对陌生人：补背景、少术语、多解释。
- 对客户：先对方关心的问题，再讲方案。

问用户：

> “这句话你对朋友会怎么说？对领导会怎么说？差别在哪？”

## 5. 精简的具体手法

### 5.1 一句一意

长句切开，每句只放一个动作/判断。

> 原句：我觉得这个方案虽然说整体上方向是对的，但是在执行层面可能还会存在一些因为资源不足而导致的风险。
> 改：方案方向是对的。但资源不够，执行会有风险。

### 5.2 去掉“的的不休”

连续出现“的”时，拆句或换动词。

> 原句：这是一个需要我们共同努力才能完成的一个比较长期的目标。
> 改：这个目标要大家一起做，时间会比较长。

### 5.3 动词优先

名词化改动词：

- 进行讨论 → 讨论
- 做出判断 → 判断
- 对……进行分析 → 分析
- 给予支持 → 支持

### 5.4 数字和事实替代程度词

- “很多人” → “我们组 8 个人里有 6 个”
- “很久” → “拖了三个星期”
- “效果不错” → “转化率从 2% 到 3.5%”

没有数字就用量词、频次、具体场景，不编数字。

### 5.5 删掉“正确的废话”

- “我们要重视这个问题。”
- “沟通是非常重要的。”
- “每个人都有自己的想法。”

删掉后如果意思不变，就删；如果这是铺垫，改成一句具体的过渡。

## 6. 自然度的具体手法

### 6.1 说给自己听

让用户把改好的段落读出来（或默读），问：

> “哪一句你读的时候会卡一下？”

卡住的地方通常就是要改的地方。

### 6.2 换三种说法

同一句话，要求用户说三个版本：

- 正式版；
- 日常版；
- 对朋友版。

不评价哪个“更好”，只问：“差别在哪？什么场合用哪个？”

### 6.3 去掉连接词

把“首先、其次、最后、综上所述”全删掉，看内容还能不能连上。能连上，说明逻辑在内容里；连不上，说明之前靠标签撑结构。

### 6.4 脱稿复述

用户写完后，不看原文，用自己的话说一遍。对比“写出来的”和“说出来的”，通常说出来的更自然。

### 6.5 角色切换

同一内容，分别说给：
- 一个很忙的领导（30 秒）；
- 一个完全不懂的家人（要解释）；
- 一个挑剔的同事（要预判质疑）。

## 7. 常用练习

| 练习 | 做法 | 练什么 |
|---|---|---|
| 压缩一半 | 同一段话，字数压到 50%，意思不变 | 精简 |
| 一句一意 | 把长句拆成 3 句以内 | 清晰 |
| 空泛词替换 | 圈出所有形容词，换成事实 | 具体 |
| 口头禅点名 | 统计“就是/然后/其实/那个”，只留必要的 | 干净 |
| 三版表达 | 正式/日常/朋友版 | 适配 |
| 脱稿重说 | 写完不看，口头复述 | 自然 |
| 删标签 | 去掉“第一第二第三” | 真结构 |
| 听众复述 | 让听者用自己的话复述，看信息有没有丢 | 有效 |

## 8. 单次训练模板（10 分钟）

1. **取一段原话**（1 分钟）：用户刚才说的，或给一个短题。
2. **标问题**（1 分钟）：只选一个——空泛/重复/长句/书面/不自然。
3. **找核心句**（1 分钟）：“只能留一句，留哪句？”
4. **改一处**（3 分钟）：只改一个维度，不全面重写。
5. **读一遍**（1 分钟）：用户读，找卡点。
6. **重说**（2 分钟）：同一内容，用改后的方式说。
7. **对比**（1 分钟）：具体少了什么、清楚在哪里。

## 9. 不要做

- 不要把“精简”变成“删到没有信息”。
- 不要把所有口语都改成书面语，也不要把所有书面语都改成网络用语。
- 不要为了“自然”加口头禅。
- 不要一次改五个地方；用户会不知道哪个动作有效。
- 不要用“文采”“高级感”作为标准。
- 不要替用户重写整段，再让他“体会一下”。
- 不要因为句子短就判“不完整”；口语里短句是正常的。

## 10. 结束标准

用户能在无提示下：

- 用一句具体的话替换一个空泛评价；
- 把一段话压到一半，核心意思不变；
- 把长句拆成能一口气说完的短句；
- 对两个不同对象，调整同一内容的说法；
- 脱稿说一遍，听起来不像背稿。

达到后，进入场景模拟，或把语言训练放到真实任务里检验。
